CASE 04 / APPLIED AI · ENGINEERING MANAGEMENT PROJECTATLASSIAN FORGE · JIRA CLOUD · NLP

Priority Assist: Explainable AI-assisted Jira issue prioritization

From an unstructured issue description to a suggested priority, a confidence score, and an explanation that a delivery team can review.

THE CHALLENGE

Manual backlog triage can be inconsistent when urgency is buried in issue summaries and descriptions, and different Jira projects use different priority labels.

WHAT I BUILT

A Jira Cloud plugin on Atlassian Forge that reads issue text and uses heuristic NLP signals to suggest urgency, show a confidence score, and explain its recommendation.

DESIGN DECISIONS

Prioritized transparency over black-box scoring: surfaced explanation tables, mapped project-specific priority labels, and made applying a suggested priority an explicit one-click user action.

OUTCOME & EVIDENCE

A working project demonstration and publicly available source repository. The video below shows the plugin workflow; no unverified accuracy or productivity metrics are claimed.
